# Repireo

Repireo is a verified service network and on-demand expert repair platform built with Next.js and Tailwind CSS. It is designed to connect users with trusted technicians for various services, including repairs, installations, and maintenance. The platform specializes in categories such as HVAC, Electrical, and Plumbing.

## Key Features

- **Expert Teams**: Access to verified and highly-rated specialists.
- **Live Tracking**: Real-time updates and job tracking features for customers.
- **Secure Booking**: A trusted network for secure and transparent transactions.
- **Wide Range of Services**: Detailed service categories including "Precision AC Care," "Reliable Power Repair," and "Leak-Free Plumbing".

## Getting Started

1. Ensure you have Node.js (>=20.0.0) installed.
2. Clone the repository.
3. Install dependencies using `npm install`.
4. Run the development server using `npm run dev`.

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technologies Used

- Next.js (React Framework)
- Tailwind CSS (Styling)
- Framer Motion (Animations)
- Lucide React (Icons)
- React Leaflet / Google Maps API (Mapping and Tracking)
